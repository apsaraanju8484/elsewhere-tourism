# Elsewhere — India Travel Website

A responsive, multi-page tourism website built as a beginner-friendly portfolio project with HTML, Bootstrap 5, custom CSS, and vanilla JavaScript.

## Pages

- `index.html` — travel landing page
- `destinations.html` — destination guide
- `experiences.html` — curated activities
- `stays.html` — accommodation highlights
- `about.html` — project story and travel values
- `plan.html` — trip enquiry form
- `booking.html` — responsive stay search and demo booking flow

## Run locally

Open `index.html` in a browser, or use the **Live Server** extension in Visual Studio Code for a local preview. Bootstrap, fonts, and photos are loaded from CDNs, so an internet connection is needed for those assets.

## What it demonstrates

- Bootstrap responsive grid and collapsing mobile navigation
- Custom responsive layouts and reusable visual styles
- JavaScript form feedback, date validation, stay filtering, and estimated booking totals
- Accessible labels, image descriptions, and page navigation

## Booking demo

The booking page uses sample stay data in `site.js`. It does not connect to a booking service, send reservations, or collect payments. Replace the sample data and connect a backend before using it for real bookings.

## Files

All HTML pages share `styles.css` and `site.js`. Bootstrap 5.3.3 is included from jsDelivr.
